This is an Interactive Image Search Gallery using the baguetteBox.js JavaScript plugin. 

Users are able to search for images using text found in the titles or captions of each image.

Captions and titles are imported using the photo_captions.txt file. 

Images are added to the DOM using the app.js file to reduce the size and complexity of the index.html file. This also allows for quick edits the the structure of the DOM without having to make edits to each individual set of images.
